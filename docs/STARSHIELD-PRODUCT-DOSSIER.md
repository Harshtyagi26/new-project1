## 0. READ THIS FIRST — How this was compiled, and what is missing

This dossier was assembled from indexed web content for starshieldpaints.com. Three limitations
materially affect completeness, and you should know them before relying on any number below.

### 0.1 The site could not be downloaded directly

The environment this was compiled in blocks outbound HTTPS to starshieldpaints.com (and to every
other non-allowlisted host) at the network egress proxy. Direct page fetches, the sitemap, the TDS
PDFs and the product images all returned `403 CONNECT tunnel failed`. Text-extraction relays
(r.jina.ai, allorigins) are blocked by the same policy.

**Consequence:** everything below comes from *search-engine indexed copy* of the pages, not from the
pages themselves. It is accurate as to product names, URLs, positioning and published claims, but it
is **not** a substitute for the actual TDS PDFs.

### 0.2 No TDS PDFs were retrieved — and no images

- **TDS PDFs:** the site exposes "Download Catalogue" / "Download TDS" buttons on individual product
  pages and a master page at `/pages/starshield-product-catalogue-and-tds`. Those PDF binaries could
  not be downloaded. Section 5 records, per product, whether a TDS is *known to be offered*.
- **Images:** no product images could be downloaded or catalogued. Shopify product images live under
  `cdn.shopify.com/s/files/...`, which was equally blocked. Section 7 explains the one-command way to
  get every image and every TDS URL once you run this from an unblocked network.

## 7. How to complete this dossier (TDS PDFs + every image)

Run these from any normal internet connection. Because the store is Shopify, the full catalogue is
available as structured JSON — no scraping required.

```bash
# 1. Every product, with all image URLs, variants, and prices — paginated JSON
for p in $(seq 1 10); do
  curl -s "https://starshieldpaints.com/products.json?limit=250&page=$p" -o "products-$p.json"
done
jq -s '[.[].products[]]' products-*.json > all-products.json

# 2. Product count and full name list
jq -r '.[] | .title + "  ->  https://starshieldpaints.com/products/" + .handle' all-products.json

# 3. Every image URL in the catalogue
jq -r '.[].images[].src' all-products.json | sort -u > image-urls.txt

# 4. Download every image
mkdir -p images && (cd images && xargs -n1 -P8 curl -sSO < ../image-urls.txt)

# 5. Sitemap -> every page, including the /pages/ landing pages that host the TDS buttons
curl -s https://starshieldpaints.com/sitemap.xml
curl -s https://starshieldpaints.com/sitemap_pages_1.xml

# 6. Harvest every TDS / catalogue PDF link across all landing pages
curl -s https://starshieldpaints.com/sitemap_pages_1.xml \
  | grep -oP '(?<=<loc>)[^<]+' \
  | while read u; do
      curl -s "$u" | grep -oiP 'https://[^"]+\.pdf' ;
    done | sort -u > tds-urls.txt

# 7. Download all TDS PDFs
mkdir -p tds && (cd tds && xargs -n1 -P4 curl -sSOL < ../tds-urls.txt)
```

`products.json` is the single highest-value call — it returns the authoritative product list with
images, variants and pack sizes, and settles definitively whether "Star Floor Paint Extreme" and
"Star Floor Shine" exist as unlisted or draft SKUs.
